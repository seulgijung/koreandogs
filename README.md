# Dogs from Korea to North America

- Data: I utilized data officially and publicly compiled and provided by South Korea's Ministry of Agriculture, Food, and Rural Affairs. You may find the same data by googling "동축산물 검역실적 (Animal and Livestock Quarantine Performance)" or just through my chart that embeds a direct link to the Korean Public Data Portal. Not only does this data count dogs that were up for adoption oversea but also were transported for relocation, but I presumed that the number of relocated dogs was is low, baesd on which my analysis was drawn.
